# Extractable components

There are no shared layout or reusable local UI components to extract. The application is a single page with inline page-specific sections in `templates/index.html`.

Potential future components, not currently reusable:

- `InputPanel` — URL input and parse action
- `VideoResultCard` — cover, metadata, statistics, and actions
- `DownloadStatus` — progress and completion states

These should remain inline for this redesign because there is only one page.
